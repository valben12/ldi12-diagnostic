## Pilotes

- **La liste des pilotes de ce PC s'affiche dès l'ouverture.** Elle ne se remplissait qu'après
  un diagnostic complet : elle restait vide, et indiquait à tort qu'il n'y avait aucun pilote
  tiers. Elle est maintenant lue directement sur le disque, sans analyse préalable.
- **Chaque pilote est étiqueté « Périphérique » ou « Propre à ce PC »**, d'après le matériel
  qu'il équipe : imprimante, scanner, webcam, souris ou clavier USB d'un côté ; chipset, carte
  graphique, Wi-Fi interne, audio intégré, pavé tactile, Bluetooth intégré de l'autre. Les
  périphériques sont en tête de liste.
- **Trois choix en un clic** sur chaque liste (ce PC, disque d'un PC client, restauration) :
  - « Même PC : tout », pour réinstaller la même machine ;
  - « PC neuf : périphériques seulement », pour transférer sur une autre machine ;
  - « Aucun ».

L'exécutable n'est pas signé : Windows annoncera « Éditeur inconnu » au téléchargement.
L'empreinte SHA-256 est jointe.
